# PG-Sheet Examples

This folder contains examples of **PG-Sheets** for publicly available property graph (PG) datasets.

## Examples

### KG20C — Scholarly Knowledge Graph

A PG-Sheet for the **KG20C Scholarly Knowledge Graph** dataset is provided as an example.

- **Dataset:** [KG20C Scholarly Knowledge Graph](https://www.kaggle.com/datasets/tranhungnghiep/kg20c-scholarly-knowledge-graph)
- **Source:** Kaggle
- **Description:** A scholarly knowledge graph dataset.

The corresponding PG-Sheet documents the dataset according to the PG-Sheet template, providing structured information about its contents, structure, and other relevant aspects of the dataset.
